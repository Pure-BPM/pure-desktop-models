# pure-desktop-models

Public downloads for the **Pure Desktop** app's AI model marketplace — the card metadata (`models.json`) plus per-model runner scripts and small assets under `models/`. The large model weights are hosted on Hugging Face, not here.

This repo is intentionally separate from the Ableton **plugin installers**, which live in [`pure-plugins-releases`](https://github.com/Pure-BPM/pure-plugins-releases).
